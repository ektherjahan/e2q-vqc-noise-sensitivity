# E2Q reproducibility release v1.0.0

Initial public reproducibility release accompanying the E2Q manuscript.

## Included

- Full benchmark Jupyter notebook with embedded frozen source bundle
- Frozen processed evidence tables and calibration provenance
- Frozen benchmark configuration, 16-architecture panel, and verdict
- Final manuscript figures
- Integrity checker and SHA-256 manifest
- Citation and licensing metadata

## Scientific scope

This release reproduces the simulation-based calibration-history benchmark. Direct physical-QPU confirmation is not part of v1.0.0 and should not be inferred from this release.

## Public-release editorial normalization

The word `preregistered` in the internal benchmark notebook/report was changed to `prespecified`/`frozen` because the protocol was internally frozen but not deposited in a public preregistration registry. This is a terminology correction only; code, thresholds, frozen inputs, and numerical results are unchanged.
